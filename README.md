# Equipara APPGG

Repositório do hotsite **Valorizar APPGGs é fortalecer São Paulo**.

Fonte da migração: artefato nativo do ChatGPT Sites, projeto `appgg-valorizacao`, versão 7.

## Objetivo

Apresentar, de forma executiva e auditável, a assimetria remuneratória projetada entre APPGGs e AMCIs no contexto do PL 699/2026, seus efeitos sobre retenção e capacidade estatal e alternativas de implementação fiscal.

## Estrutura migrada

- Nota de decisão em quatro blocos;
- comparação remuneratória APPGG × AMCI;
- seção fiscal e de implementação;
- horizonte remuneratório de 10 anos;
- referências e premissas metodológicas.

## Observação

O artefato do ChatGPT Sites não expõe diretamente seu código-fonte completo para exportação. Por isso, este repositório foi inicializado a partir do conteúdo textual e dos dados estruturados recuperáveis do projeto publicado. A reconstrução visual deve preservar o conteúdo e ser feita em código aberto neste repositório.
